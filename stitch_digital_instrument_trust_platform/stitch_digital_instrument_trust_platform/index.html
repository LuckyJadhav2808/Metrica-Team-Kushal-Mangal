Project Architecture & Technology Stack

This repository delivers the Smart India Hackathon (SIH 2026) Problem Statement #26036 solution for the Department of Consumer Affairs. It bridges permanent hardware digital identity with real-time verification lifecycles.

Frontend Framework Next.js 15 (App Router), React 19, Tailwind CSS, Lucide Icons
Backend & Persistence SQLite with Prisma ORM, Supabase Cloud sync, In-memory reactive store
Security & Auth Bcrypt password hashing, Jose JWT middleware, HMAC-SHA256 digital seals
Field Offline Mode Service worker cache, offline verification queue, background sync
